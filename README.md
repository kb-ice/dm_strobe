# dm_strobe
- 入力信号の周波数を測定し，その4倍の周波数の信号を出力します
- パワーLED等をストロボとして使うためのパルス波を出力します
- 入力信号と出力信号の位相がだいたい同期しています

## 使用マイコン
ATtiny2313

他のAVRマイコンでも，8bitタイマーとキャプチャ機能付きの16bitタイマーが備わっていれば，少しプログラムを書き換えるだけで移植できると思います。

## 使用方法
回転体に磁石を2個つけて，マイコン側に接続したホールICで回転を検出する，という使い方を想定しています。この場合，出力信号の周波数は回転体の回転数の8倍になります。また，それぞれの磁石の磁力の差や取り付け位置のずれにより，入力信号の周波数が周期的に変動することがあります。プログラム中で，8bitタイマーが入力信号の2分周器として使われているのは，この変動を吸収するためです。

> [!NOTE]
> OC0BピンとICPピンは必ず接続してください。
